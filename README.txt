THE BRIEFLINE — NEWS WEBSITE DEMO
================================

FILES
- index.html   Main website structure
- style.css    Responsive design and theme styles
- script.js    News content and interactive features

HOW TO RUN
1. Keep all three files in the same folder.
2. Double-click index.html to open it in a modern browser.
3. An internet connection is recommended for Google Fonts and the demo editorial photographs.

FEATURES
- Responsive English-language news homepage
- Breaking news ticker
- Featured story and latest news cards
- Category filtering and story search (Ctrl + K)
- Article reading view and share action
- Saved stories / reading list
- Newsletter demo form
- Light and dark reading modes
- Demo editor panel: add, edit, feature and delete stories
- Story and reading-list data saved in browser localStorage

DEMO EDITOR
- Click the Editor button in the header or footer.
- Demo password: briefline
- The editor is a front-end demonstration only. It is not a secure authentication system and does not publish to a server.

IMPORTANT
- The sample stories are demonstration content, not live reporting.
- Images are loaded from Unsplash URLs and therefore require an internet connection.
- For a real news channel, connect a secure backend, database, authentication system, image storage and a server-side CMS before publishing.
